# Lab-2
Short summary: 
Problem Statement: I want to make a model that can look at an email and decide if it is spam or not. This helps filter out junk messages automatically.

Dataset Description: I am using a file called email.csv. It has a column called Message which has the text of the email, and a column called Category that labels it as either "spam" or "ham".

Machine Learning Problem Type: This is a Supervised Learning and Classification problem. It is classification because the model is sorting messages into two groups: spam or not spam.

Target Variable: The target variable is the Category column, because that is what I want the model to predict.
